# Simple Linear Regression - Salary Prediction

A hands-on implementation of Simple Linear Regression for predicting salary based on years of work experience using Python and scikit-learn.

## 📊 Project Overview

This project demonstrates the implementation of Simple Linear Regression using a real-world salary dataset.

The main goal is to analyze the relationship between years of work experience and salary, build a linear regression model, make predictions, and evaluate the model's performance.

## 🎯 Objectives

- Perform exploratory data analysis on salary and work experience data
- Prepare the dataset for machine learning
- Implement Simple Linear Regression using scikit-learn
- Visualize the relationship between years of experience and salary
- Evaluate model performance using regression metrics
- Understand the practical workflow of a machine learning regression problem

## 📁 Dataset

The dataset contains information about employees' years of work experience and their salaries.

### Features

- `YearsExperience` - Years of professional work experience

### Target

- `Salary` - Employee salary

The dataset is used to investigate whether there is a linear relationship between work experience and salary.

## 🛠️ Technologies Used

- **Python 3**
- **Jupyter Notebook**
- **pandas** - Data manipulation and analysis
- **numpy** - Numerical computations
- **matplotlib** - Data visualization
- **scikit-learn** - Machine learning and model evaluation
